GNJOY.HK 회원정보 관리, 신원 본인인증, SNS 연동 및 메시지함 기획 명세

id="spec-pin1">
1 GNB (공통) 레이아웃
  • 공통 다크 네비게이션 적용
  • 마이페이지 진입 시 활성화된 상단 메뉴 없음
2 프로필 헤더 카드 컴포넌트
  • 다크 그라데이션 배경, Full Width 컨테이너 사이즈
  • 좌측: 아바타 이미지, 닉네임, VIP 등급 뱃지 표시
  • 우측: 계정 ID, 상태(정상/정지), 보안 등급(녹색 텍스트), 가입일 표시
3 마이페이지 주요 탭 네비게이션
  • 기본 정보 관리 / 본인 인증 센터 / 소셜 계정 연동 / 개인 메시지함
  • 활성 탭에 하단 Red Border 라인 적용 (Active State)
4 회원 기본 정보 수정 폼 폼 인터랙션
  • 2-Column Grid 구조 (최대 너비 960px, 각 필드 480px 이하)
  • 플랫폼 계정 ID, 생년월일: Readonly/Disabled 속성 적용
  • 닉네임: 30일 변경 쿨타임 안내 문구 추가
  • 휴대폰, 이메일: '인증 완료' 뱃지 및 변경 버튼 제공
5 MID 인증 현황 컴포넌트
  • 미인증 상태일 경우 Amber 컬러의 경고 아이콘 표시
  • '본인인증 진행하기' 버튼을 통한 인증 프로세스 유도
6 신분증 실명인증 현황 컴포넌트
  • 인증 완료 시 Green 컬러의 아이콘과 뱃지 표시
  • 인증 일자와 남은 변경 횟수(예: 2회/3회) 안내
7 SNS 연동 현황 리스트 리스트
  • Google, Apple ID, Facebook 플랫폼 지원
  • 연동 완료 상태: Green 텍스트 및 연동된 이메일 일부 표시, [연동 해제] 버튼 제공
  • 미연동 상태: Gray 텍스트, Primary [지금 연동하기] 버튼 제공
  • 경고 문구: 연동 해제 시 2차 인증 필요 안내 텍스트 하단 배치
8 메시지 필터 & 리스트 리스트
  • 필터 탭: 전체, 시스템 공지, 결제 알림, CS 답변 (카운트 표시)
  • 리스트 항목: 카테고리 뱃지, 제목, 날짜, 읽음 여부 상태
  • 안읽음 상태의 항목은 제목을 볼드 처리 및 뱃지 컬러 강조
  • 하단에 "메시지는 수신일로부터 90일간 보관됩니다." 정책 문구 안내
