로그인 회원가입

GNJOY.HK 소셜 인증, 플랫폼 로그인 및 신규 회원가입 기획 명세

id="spec-1" onclick="highlightSpec(1)">
1
GNB 영역 (Dark)
Layout
  • 로그인 화면에서는 시각적 대비를 위해 Dark 테마 GNB를 사용합니다.
  • 현재 활성화된 메뉴(Active) 표시를 하지 않습니다.
2
2-Column Split Auth 레이아웃
Layout
  • 좌측 55%, 우측 45% 비율의 Split 화면 구조를 가집니다.
  • 좌측: 브랜드 슬로건 및 게임 포털로서의 아이덴티티 강조.
  • 우측: 인증(로그인) 폼을 백색 배경의 카드 형태로 배치하여 집중도 향상.
3
소셜 로그인 영역
Function
  • 지원 플랫폼: Google, Apple ID, Facebook
  • 글로벌(HK) 환경에 맞춰 3대 주요 소셜 로그인을 상단에 배치하여 접근성을 높입니다.
4
플랫폼 로그인 폼 & 보안
Function
  • GNJOY 계정(ID 또는 이메일) 및 비밀번호를 통한 일반 로그인.
  • 봇 공격 방지 및 보안을 위해 Cloudflare Turnstile 위젯을 삽입합니다.
  • Enter 키 입력 시 로그인 버튼 클릭과 동일하게 동작합니다.
5
유틸리티 링크
UI
  • 비밀번호 찾기, 아이디 찾기 링크 제공.
  • 신규 유저 인입을 위한 회원가입 페이지 유도 링크 제공.
6
약관 동의 영역
Function
  • '전체 동의' 체크 시 하위 필수/선택 항목이 모두 체크/해제됩니다.
  • [필수] 항목 미동의 상태에서 가입 진행 시, 알림(Toast/Alert) 제공.
  • '보기' 클릭 시 레이어 팝업으로 상세 약관 내용을 표시합니다.
7
회원가입 입력 폼
Data
  • GNJOY ID: 영문/숫자 조합 4~16자, 중복확인 필수.
  • 비밀번호: 영문+숫자+특수문자 조합 8~16자 (보안수준 실시간 체크 표시 고려).
  • 이메일: 인증요청 버튼을 통해 실제 소유 확인(이메일 발송/코드입력 또는 링크 방식).
  • 닉네임: 최대 20자, 커뮤니티 및 고객지원에서 노출될 이름.
