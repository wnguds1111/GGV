1
Global Navigation Bar (GNB)
Common
  • 고객지원 메뉴 활성화 상태 표시 (Active state)
  • 화면 스크롤 시 상단에 고정 또는 디자인 시스템 기준에 따름
2
고객지원 2단 레이아웃
Layout
  • 좌측 220px 고정 LNB (Local Navigation Bar) 배치
  • 우측 콘텐츠 영역 가변형 flex 할당
  • 하단에 운영시간 안내 정보 노출
3
FAQ 검색 및 필터
Interaction
  • 게임 선택 드롭다운으로 특정 게임 FAQ 필터링 지원
  • 키워드 검색을 통한 실시간 결과 제공 가능 (또는 서버 검색)
  • 카테고리 탭 (전체, 계정, 결제 등) 클릭 시 목록 갱신
4
FAQ 아코디언 리스트
Component
  • 질문 클릭 시 하단에 답변 내용 확장 노출 (Collapse/Expand)
  • 답변 영역 내에 추가 링크, 버튼 배치 가능
  • 카테고리 태그 뱃지 노출
5
문의 분류 선택
Form
  • 게임 선택 후 연계된 대분류/소분류 옵션 동적 갱신
  • 인게임 문의일 경우 서버 및 캐릭터명 입력 활성화
6
신청자 정보 입력
Form
  • 로그인 상태 시 계정 정보(이름, 이메일, 연락처) 자동 매핑
  • 수정 가능한 필드로 제공
7
문의 내용 및 첨부파일
Form
  • Drag & Drop 영역 또는 클릭하여 파일 탐색기 호출
  • 최대 5개, 총 20MB 용량 제한 및 파일 타입 체크
8
보안 검증 및 접수 완료
Action
  • 봇 방지용 Cloudflare Turnstile 또는 reCAPTCHA 적용
  • 필수값 유효성 검증 완료 후 문의 접수
9
의견 피드백 폼
Form
  • 개선 제안, 버그 리포트 등 유형 선택
  • 간단한 제목 및 내용 입력 후 즉각 제출 가능토록 UX 최소화
