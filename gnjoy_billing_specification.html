캐시충전

GNJOY.HK 온라인 캐시 충전 및 거래 결제내역 조회 기획 명세

id="pin1">
1 글로벌 네비게이션 바 (GNB) Header
  • 공통 GNB 컴포넌트 사용
  • 화면 진입 시 '캐시충전' 메뉴에 활성화(Active) 상태 표시
  • 우측 영역에 로그인/회원가입 또는 회원 정보 표시 (로그인 상태에 따라 분기)
2 계정 정보 & 결제 프로세스 위저드 Wizard
  • 상단에 로그인한 사용자의 GNJOY ID 및 현재 계정 상태(정상/정지) 노출
  • 현재 보유 중인 캐시(P) 잔액을 강조하여 표시
  • 충전 진행 단계를 3단계(충전 정보 입력 → 결제 정보 확인 → 완료)로 시각화
  • 현재 진행 중인 단계(Step 1)를 컬러로 활성화 처리
3 게임/서버/캐릭터 선택 영역 Form
  • 사용자가 플레이 중인 게임 리스트를 드롭다운으로 제공
  • 게임 선택 시 해당 게임의 서버 목록을 비동기로 불러와 갱신
  • 서버 선택 시 해당 서버 내 사용자 캐릭터 목록 갱신
  • 선택 전 상태에는 '선택해주세요' 플레이스홀더 텍스트 표시
4 결제 수단 선택 그리드 Grid
  • 지원되는 결제 수단을 아이콘과 함께 카드 형태로 배열
  • 신용카드, 계좌이체, 모바일/페이 등 다수 결제 수단 지원
  • 특정 결제 수단 선택 시 활성화 상태 표시(보더 컬러 변경 등)
  • 결제 수단별 점검 시간 또는 장애 발생 시 비활성화(Disabled) 처리 및 툴팁 안내
5 충전 금액 선택 Form
  • 미리 정의된 결제 금액 단위 옵션 제공 (₩5,000 ~ ₩100,000)
  • 선택한 결제 수단에 따라 충전 가능한 금액 옵션이 동적으로 변경될 수 있음
  • 금액 선택 시 지급될 기본 캐시와 보너스 캐시를 분리하여 명시
6 보안 경고 및 제출 버튼 Security
  • 사기 피해 예방 및 결제 주의사항을 경고 컬러(Amber)로 눈에 띄게 배치
  • 매크로 및 봇 방지를 위한 Turnstile/ReCaptcha 보안 모듈 연동
  • 필수 항목(게임, 캐릭터, 결제수단, 금액) 모두 선택 시 '결제 진행하기' 버튼 활성화
  • 버튼 클릭 시 결제 정보 확인 모달 또는 PG사 결제창으로 이동
7 결제 내역 필터링 Filter
  • 조회할 게임 종류별 필터링 기능 제공
  • 결제 상태(결제완료, 취소, 실패 등)에 따른 필터 제공
  • 기간 선택 (최근 30일, 90일, 전체 등) 드롭다운으로 조회 기간 설정
  • 조회 버튼 클릭 시 조건에 맞는 데이터 리로드
8 거래 및 결제 내역 테이블 Table
  • 주문번호, 날짜, 게임/캐릭터 정보, 결제 수단, 금액 등 주요 정보 리스팅
  • 주문번호 클릭 시 결제 영수증 또는 상세 내역 팝업 제공
  • 상태(완료, 취소 등)는 뱃지(Badge) 컴포넌트로 시각적 구분
  • 하단에 페이지네이션을 통해 다수 내역 탐색 지원
