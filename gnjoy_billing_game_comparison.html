1. 게임선택별 (xGameId) 연동 흐름 & 핵심 정책 상세 비교

드롭다운에서 선택한 게임 코드값(ROBA, ROO, RORB, ROTL)에 따라 UI 폼 구성 요소 및 백엔드 연동 데이터 방식이 완전히 달라집니다.

RO仙境傳說：初心之戰
라그나로크: 초심지전 (Origin / Classic MMORPG)
ROBA
  • 서버 선택 (xServerId) 일반 1단계 서버 드롭다운
  • 캐릭터 연동 (xPlayer) GetRoleList AJAX 동적 캐릭터 조회
  • 결제 카테고리 8개 탭 전체 활성화
  • 대표 상품 마이캐시 / 루비 / 일반 패키지
  • 특이사항 기본 대만/홍콩 결제 표준 가이드 적용
RO仙境傳說：愛如初見
라그나로크: 애루초견 (Ragnarok Origin 3D)
ROO / ROM
  • 서버 선택 (xServerId) 일반 1단계 서버 드롭다운
  • 캐릭터 연동 (xPlayer) GetRoleList AJAX 동적 캐릭터 조회
  • 결제 카테고리 8개 탭 전체 활성화
  • 특수 상품 (월카드) 月卡 (월카드) + B格貓金幣
  • 월카드 구매 규칙 MyCard & GASH 300원권 선택 필수
RO仙境傳說：重生
라그나로크: 중생 (Ragnarok: Rebirth Idle RPG)
RORB / ROZ
  • 서버 선택 (xServerId) 일반 1단계 서버 드롭다운
  • 캐릭터 연동 (xPlayer) GetRoleList AJAX 동적 캐릭터 조회
  • 월카드 혜택 (720시간) Rodex 우편함으로 4종 아이템 지급
  • 월카드 재구매 제한 잔여일 10일 미만 시 재구매 허용
  • 특이사항 구매 즉시 30일(720시간) 뒤 순연 계산
RO仙境傳說：曙光
라그나로크: 서광 (Ragnarok: Twilight RPG)
ROTL
  • 서버 선택 (xServerNamePre) 2단계 서버 접두사 드롭다운 추가
  • 캐릭터 연동 (xPlayer) 2차 서버 지정 후 캐릭터 선택
  • 계정 바인딩 조건 FB 계정 접속 시 마이페이지 바인딩 필수
  • 결제 카테고리 필터 백엔드 연동에 따라 소액/모바일 제어
  • 특이사항 GetServerNamePre AJAX 전용 API 사용

3. 결제 보안, 본인인증(MID) & 운영 특이사항
📱 MID (門號身分識別) 통신사 소액결제 본인인증 규칙

대만 통신사 소액결제(#payPath_04) 사용 시, 3,000 TWD 이상 단건 결제 또는 30일 이내 누적 5,000 TWD 이상 결제 시 /Billing/forAjax_Check_Nd_Go_Mid로 자동 검증을 거칩니다.
인증 미완료 상태일 경우 [MID 門號身分識別] 버튼이 활성화되며, 유저는 https://www.gnjoy.hk/Mid로 이동하여 통신사 본인인증을 마쳐야 결제가 진행됩니다.

⚠️ Apple Pay & 브라우저 호환성 정책

Apple Pay(#payPath_08)는 iOS Safari 브라우저에서만 정상 작동하도록 제한되어 있으며, Safari 설정 내 [팝업 차단(Block Pop-ups)] 옵션이 켜져 있을 경우 결제창 호출 실패 사례가 발생하여 안내 레이어(NoticePn_mobile)가 팝업됩니다.
